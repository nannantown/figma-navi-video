# アカウント一式（名前・@・プロフィール文・アイコン）の案 — 新作AIツール pickup

- 作成 2026-09-22。**ここにあるのは案で、IG / YouTube の設定変更はオーナーが行う**（この作業をした worker は IG / YouTube にログインしていない・設定を触っていない）。
- 対象は figma-navi-video が投稿している 2 アカウント。発信の中身は「今日の新作 AI ツール pickup（Product Hunt の公式 Atom フィードの新着。**順位・票数・人気は名乗らない**）」で、読み手は **非エンジニアで今日使えるツールを探している人**。
- Figma / デザイン系の語は使わない（旧ジャンルは `docs/strategy-archive/2026-04-design-news.md` に記録として終了済み）。
- `docs/channel-copy.md` の「アカウント名（2026-09-16 オーナー決定: 変えない）」は、**2026-09-22 のオーナー指示（名前も含めた一式を作る）でこのファイルに引き継がれた**。名前を変えるかどうかを最後に決めるのはオーナー。
- YouTube のチャンネル名「HAL- AI情報カフェ」(`@hal-ai-9000`) は AI 汎用で矛盾しないため、**変えない前提**で IG 側をそこに寄せている（2026-09-16 決定）。

---

## 1. 表示名の候補（IG の「名前」欄 / 必要なら YouTube 側も同じ考え方）

| # | 表示名 | なぜこの名前か |
|---|---|---|
| **A（第 1 推奨）** | **`HAL｜毎朝の新作AIツール`** | YouTube の「HAL」を残したまま、名前だけで中身（毎朝・新作・AIツール）が分かる。IG の名前欄は検索対象なので「AIツール」が入るのが効く |
| B | `毎朝AIツール` | ブランド名を捨て、探している言葉だけで構成。発見されやすさは一番強いが、YouTube とのつながりは弱くなる |
| C | `AI情報カフェ` | YouTube のチャンネル名とほぼ同じにして「同じ発信者」と一目で分かる形。ただし何を配るアカウントかは名前から読めない |

**YouTube 名との整合**: YouTube は「HAL- AI情報カフェ」のまま変えない。A なら頭の「HAL」が共通なので、IG と YouTube が同じ発信者だと分かる。B を選ぶ場合は、プロフィール文の末尾に「YouTube もやっています（HAL- AI情報カフェ）」の 1 行を足して繋ぎを作るのがよい。

## 2. IG ユーザーネーム（@）の候補

英数と `_` `.` のみ。既存の YouTube ハンドル `@hal-ai-9000` はハイフンを含むが、**IG はハイフンを使えない**ので `_` に置き換える形が一番近い。空き確認はオーナーが行う前提で、第 3 案まで用意した（全部 15 文字以内）。

| # | @ | 文字数 | `@hal-ai-9000` との関係 |
|---|---|---|---|
| **1（第 1 推奨）** | `hal_ai_daily` | 12 | `hal` + `ai` を引き継ぎ、末尾の数字を「毎日」に置き換えた形。数字が無いぶん読み違えられにくい |
| 2 | `hal_ai_tools` | 12 | 同じく `hal_ai` を引き継ぎ、末尾を中身（tools）に。1 が取れないときの第一候補 |
| 3 | `shinsaku_ai` | 11 | HAL を使わず中身だけ。日本語話者が読んで意味が分かる（新作 AI） |
| （予備） | `hal_ai_9000` | 11 | YouTube ハンドルの数字まで揃えた形。1〜3 が全部埋まっていた場合の保険 |

## 4. プロフィールアイコン

| ファイル | 中身 |
|---|---|
| `assets/brand/profile-icon.png` | **本番用。1080×1080 PNG。これをそのまま IG / YouTube にアップロードする** |
| `assets/brand/profile-icon.svg` | 元データ（色や形を直すときはこちらを編集して書き出す） |
| `assets/brand/icon-preview-40px.png` | 40×40 に縮めた実物（小さく表示したときの確認用） |
| `assets/brand/icon-preview-40px-zoom.png` | 上を 10 倍に拡大した確認画像。左＝四角のまま、右＝IG / YouTube と同じ丸く切った状態 |

- 色と字は既存の動画のブランド定義 `src/components/theme.ts` から流用（背景 `#0b0b14` / アクセントのグラデーション `#8B7CFF` → `#C9C2FF`）。動画の冒頭 `src/components/Opening.tsx` と同じ、右上のうっすらした光も入れている。
- 図案は「AI」の太字＋右上の**きらめき（＝新作）**＋下のアクセント線。40px でも「AI」が読めることを縮小画像で確認済み。IG / YouTube はプロフィール画像を丸く切るため、要素は中央の円の内側に収めている。
- 書き出しコマンド（`rsvg-convert` と `ImageMagick` が必要）:
  ```sh
  rsvg-convert -w 1080 -h 1080 assets/brand/profile-icon.svg -o assets/brand/profile-icon.png
  magick assets/brand/profile-icon.png -resize 40x40 assets/brand/icon-preview-40px.png
  ```

## 6. オーナーがやること（どの画面で何を貼るか）

### Instagram（スマホアプリ）

1. プロフィール画面 → **「プロフィールを編集」**
2. **名前** … 上の「1」から選んだ表示名を貼る（第 1 推奨は `HAL｜毎朝の新作AIツール`）
3. **ユーザーネーム** … `hal_ai_daily` を入力。すでに使われていたら `hal_ai_tools` → `shinsaku_ai` → `hal_ai_9000` の順で試す
   - ⚠️ @ を変えると、これまでの投稿に貼られた `@旧ID` のリンクは切れる。変えた直後は「@が変わりました」の 1 本を投稿しておくと安心
4. **自己紹介** … 上の「3-1」の案 1（絵文字なし）か案 2（絵文字あり）を貼る
5. **写真を変更** … `assets/brand/profile-icon.png` を選ぶ（スマホに送ってから選択）
6. ハイライトを整えるなら「5」の並びと名前を使う。固定投稿は投稿の「…」→ **「プロフィールに固定」**

### YouTube（パソコンの YouTube Studio）

1. 左メニュー **「カスタマイズ」** → **「基本情報」** タブ
2. **説明** … 上の「3-2」の完成テキストを貼る（絵文字なし／ありのどちらか）
3. **名前は変更しない**（「HAL- AI情報カフェ」のまま。2026-09-16 の決定）
4. 同じ画面の **「ブランディング」** タブ → **プロフィール写真**に `assets/brand/profile-icon.png` をアップロード
5. 保存（右上の「公開」）

### 決めたあとにやること

- 採用した表示名・@ をこのファイルの先頭に「採用: ○○（YYYY-MM-DD）」と 1 行足す
- 親リポ `sns-hub` の `CLAUDE.md` の収容プロジェクト表にある IG / YouTube 名を、採用した名前に書き換える（現状は「案の採用後にオーナーが更新する」と注記済み）
