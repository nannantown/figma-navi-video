## 選んだあとにオーナーがやること

名前・@・アイコンは**3 つとも同じ日にまとめて変える**のがよい（見た人が「別のアカウント？」と迷う期間を短くする）。

### Instagram（スマホアプリ）

1. プロフィール →「プロフィールを編集」
2. **名前** … 選んだ案の IG 表示名を貼る。⚠ 名前は 14 日間に 2 回までしか変えられないと言われている（公式ヘルプの本文は今回読み取れず未確認。日本語の解説記事や利用者の報告はどれも同じ「14 日で 2 回」なので、ほぼ確かと見てよい）。決めてから 1 回で入れる
3. **ユーザーネーム** … 選んだ案の @ を上から順に入力し、空いているものに決める。⚠ 手放した旧 @ は他の人が取れるようになる。これまでの投稿に書いた `@旧名` は切れる
4. **写真を変更** … 選んだ案の `profile-icon.png`（スマホに送ってから選ぶ）
5. 自己紹介を変える場合は上の下書きを貼る

### YouTube（パソコンの YouTube Studio）

1. 左メニュー「カスタマイズ」→「プロフィール」タブ（名前・ハンドル・写真がこのタブにある）[^yt-name]
2. **名前** … 選んだ案の表示名（IG と同じ）。⚠ チャンネル名は **14 日間に 2 回まで**。名前を変えると確認バッジは外れる（このチャンネルには付いていない）[^yt-name]
3. **ハンドル** … 案 A〜C は選んだ案の @ に変える。**案 D なら変えない**（`@hal-ai-9000` のまま）。⚠ ハンドルも **14 日間に 2 回まで**。変えてから 14 日間は旧ハンドルが自分用に確保され、旧 URL も新 URL も両方使える。14 日を過ぎると旧ハンドルは他の人が取れるようになる[^yt-handle-change]
4. **プロフィール写真** …「変更」から選んだ案の `profile-icon.png`（PNG、15MB 以下、98×98 以上で表示できる画像が条件。1024×1024 なので満たしている）[^yt-photo]
5. 右上の「公開」で確定

  ```sh
  # 3. 確認画像（左＝四角 / 右＝円形クロップ。どちらも 40px から 10 倍に拡大）
  magick -size 1080x1080 xc:black -fill white -draw "circle 540,540 540,0" /tmp/mask.png
  magick assets/brand/profile-icon.png /tmp/mask.png -alpha off -colorspace sRGB \
    -compose CopyOpacity -composite /tmp/circ.png
  magick /tmp/circ.png -background white -flatten -resize 40x40 \
    -filter point -resize 400x400 -bordercolor "#888888" -border 1 /tmp/c40z.png
  magick assets/brand/icon-preview-40px.png \
    -filter point -resize 400x400 -bordercolor "#888888" -border 1 /tmp/s40z.png
  magick /tmp/s40z.png /tmp/c40z.png +append assets/brand/icon-preview-40px-zoom.png
  ```

## 6. オーナーがやること（どの画面で何を貼るか）

### Instagram（スマホアプリ）

1. プロフィール画面 → **「プロフィールを編集」**
2. **名前** … 上の「1」から選んだ表示名を貼る（第 1 推奨は `HAL｜毎朝の新作AIツール`＝ 14 字）
   - ⚠️ 名前欄は **14 日間に 2 回までしか変えられない**。迷っている状態で試し打ちせず、決めてから 1 回で入れる
   - 上限は 30 字（ユーザーネームと同じく公式ヘルプで数字を確認できなかったため、実装上の上限として。候補はすべて 14 字以内なので影響なし）
3. **ユーザーネーム** … `hal_ai_daily` を入力。すでに使われていたら `hal_ai_tools` → `shinsaku_ai` → `hal_ai_9000` の順で試す
   - ⚠️ @ を変えると、これまでの投稿に貼られた `@旧ID` のリンクは切れる。変えた直後は「@が変わりました」の 1 本を投稿しておくと安心
   - ⚠️ **手放した旧 @ は他人が取得できる**。なりすましに使われたくない場合は、旧 @ を別のサブアカウントで押さえておくか、@ を変えずに「名前」と自己紹介だけ差し替える選択もある
4. **自己紹介** … 上の「3-1」の案 1（絵文字なし）か案 2（絵文字あり）を貼る
5. **写真を変更** … `assets/brand/profile-icon.png` を選ぶ（スマホに送ってから選択）
6. ハイライトを整えるなら「5」の並びと名前を使う。固定投稿は投稿の「…」→ **「プロフィールに固定」**

### YouTube（パソコンの YouTube Studio）

1. YouTube Studio の左メニュー **「カスタマイズ」** → **「プロフィール」** タブ（名前・説明・ハンドル・プロフィール写真はすべてこの 1 つのタブにまとまっている）[^yt]
2. **説明** … 上の「3-2」の完成テキストを貼る（絵文字なし／ありのどちらか）
3. **プロフィール写真** … 同じ「プロフィール」タブの写真の **「変更」** をクリックし、`assets/brand/profile-icon.png` を選ぶ
4. **名前とハンドルは変更しない**（「HAL- AI情報カフェ」/ `@hal-ai-9000` のまま。2026-09-16 の決定）
5. 右上の **「公開」** をクリックして確定（保存ボタンではなく「公開」）

[^yt]: YouTube ヘルプ「YouTube チャンネルのプロフィールを管理する」 https://support.google.com/youtube/answer/2657964?hl=ja （名前・説明・ハンドル。2026-09-22 確認）／ 同「チャンネルのブランディングを管理する」 https://support.google.com/youtube/answer/10456525?hl=ja （プロフィール写真。2026-09-22 確認）。旧 UI の「基本情報」「ブランディング」というタブ名は現在は無く、「プロフィール」タブに統合されている。
