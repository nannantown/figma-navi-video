# AI 仕事術（lesson）— 見本のコマ（2026-10-22）

ネタ帳 `data/ai-lesson-stock.json` の回を、本番と同じ流れ（`npm run dry-run:lesson` と同じ: 音声合成・BGM・Remotion の書き出し、メイあり `MAY_CHARACTER=on`、投稿なし）で動画にし、ffmpeg でコマを切り出したもの。オーナー向けの同じ画像は sns-hub の Canvas「AI Ground 教育動画の見本」。

| ファイル | 中身 |
|---|---|
| `sample-frames.jpg` | 要約の回「長い文章は3行で要約」の通し: オープニング / 1. 困りごと（flow の図）/ 2. そのまま使える頼み方（prompt: 入力欄に文が打ち込まれ、送信ボタンが光る）/ 3. 答えの例（answer: 箇条書きは項目ごとに改行）/ 4. ひとこと注意（steps）/ エンディング（各 360×640） |
| `prompt-answer-mail-sheet.jpg` | メールの回「断りのメールを丁寧に」と表計算の回「エクセルの式は日本語で聞く」の 2・3 枚目 |

動画の長さは 1 本 約 40 秒（要約の回 41.7 秒）。見た目やネタ帳の文面を変えたら撮り直す。
