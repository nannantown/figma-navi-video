（Android のアプリでも同じく［プロフィール］→［プロフィールを編集］→［完了］。）

   - ⚠ チャンネル名を変えると **認証バッジ（チェックマーク）が外れ**、付け直すにはもう一度申し込みが要る。ハンドルを変えてもバッジは外れない。[^yt-badge] 認証の申し込みには登録者 10 万人が要る[^yt-badge]ので、登録者 203 人（2026-09-30）のこのチャンネルには今バッジは無いはずで、バッジの点では、名前を変えても失うものは無い（2026-09-30 に公開ページを見たときも、バッジの印は見当たらなかった）。
   - 新しい名前が YouTube 全体に出そろうまで、**数日かかる**ことがある。その間、古い名前「HAL- AI情報カフェ」が見える場所が残る。[^yt-edit]
2. **ハンドル（@）**: ハンドルの横の編集アイコン → Instagram で取れたものと同じ文字列を入れる（Instagram が ① `ai_meilog` なら `ai_meilog`）。使えないと出たら 0 章の ① `ai_meilog` → ② `mei_ai_log` → ③ `meilog_ai` の順に試す →［保存］。**リンク切れを避けたいなら変えずに `@hal-ai-9000` のままでもよい**（0 章の「YouTube の @ を変えるかどうか」）。
   - ハンドルは 3〜30 字。アンダーバー・ハイフン・ピリオドは使えるが、先頭と末尾には置けない。大文字と小文字は区別されない。[^yt-handle]
   - ⚠ ハンドルも **14日間に2回まで**。[^yt-edit]
   - 変えたあと **14日間は元のハンドル `@hal-ai-9000` が自分用に確保され、その間は元に戻せる**。この間は古い URL（`youtube.com/@hal-ai-9000`）も新しい URL も両方使える。14日を過ぎると元のハンドルはほかの人が取れるようになる。[^yt-handle-change]
3. **プロフィール写真（アバターの顔にすると決めた場合だけ）**: 編集画面でプロフィール写真（丸）をタップ → 送っておいた `profile-icon.png` を選ぶ →［保存］。
