## ⚠ 変える前に確認（特許庁 J-PlatPat・パソコンで 10 分ほど）

「AI GROUND」そのものの登録商標は見つからなかったが、**「GROUND」だけの登録商標がある（ソフト・IT の区分を含む）**。紛らわしくないかを、変える前にオーナーが公式の J-PlatPat で確かめる。

1. パソコンで https://www.j-platpat.inpit.go.jp/ を開く。
2. 上のメニューの「商標」→「商標検索」を選ぶ。「検索対象種別」は「出願・登録情報」のまま。
3. 「検索項目」を「称呼(類似検索)」にして、`グラウンド` を入れて「検索」。次に `エーアイグラウンド` でも検索（似た音も拾われる）。
4. 「検索項目」を「商標(検索用)」に変えて、`GROUND`、`AIGROUND`、`AIグラウンド` を順に入れて検索。
5. 多すぎるときは、区分の欄に `9 38 41 42`（ソフト・配信・教育や娯楽・IT サービス）を入れて絞る。
6. 出てきた番号を開いて、「ステータス」が「存続」か、持ち主は誰か、何の商品・サービスで登録しているかを見る。
7. **迷ったら弁理士に聞く**（この手順書では、使ってよいかの判断はしていない）。問題がありそうなら設定を変えずに司令塔へ伝える。

あわせて知っておくこと: AI を使った物流の会社「GROUND株式会社」がある（分野は違う）。Instagram の `ai.ground`、YouTube の「AI_GROUND」「AIGround」は既にある（どれも休眠に見える）。表示名にひとこと「毎朝1分のAIニュース」を付けるのは、これらと見分けるため。

（操作の出典: INPIT「J-PlatPat 操作マニュアル」第 7 章「商標」 https://www.inpit.go.jp/content/100888006.pdf ）

### 3) YouTube の @ を変えるかどうか（オーナーが決める）

| | A. 今の `@hal-ai-9000` を残す | B. `@ai_ground` に変える |
|---|---|---|
| 良いところ | これまでの動画の説明・ほかのサイト・親のメモにある `youtube.com/@hal-ai-9000` のリンクがずっと使える。作業が 1 つ減る | 名前「AI Ground」と @ がそろい、Instagram とも同じ @ になる。検索や口頭で伝えやすい |
| 気になるところ | 名前は AI Ground なのに、@ に旧名の「hal」が残る | 変えてから **14 日を過ぎると古い `@hal-ai-9000` のリンクが使えなくなり**、ほかの人が `@hal-ai-9000` を取れるようになる。古いリンクがよその人のチャンネルを指さないよう、14 日以内に親のメモなどのリンクを直す（3 章）。すでに公開した動画の説明に書いた古いリンクは、直さない限り切れる |

- 迷ったら **A（残す）** で始めて、あとから B に変えてもよい（@ の変更は 14 日間に 2 回まで）。
- `@ai_ground` は 2026-10-01 時点で公開チャンネルなし（空いている見込み）。予備は ② `@ai_ground_jp` ③ `@ai_ground_daily`（どちらも公開チャンネルなし）。`@aiground`（アンダーバーなし）は使用中。

## 1. Instagram（スマホのアプリ）

**変える場所**（iPhone アプリの公式の手順）: 右下の［プロフィール］（または自分のプロフィール写真）→［プロフィールを編集］。ここに名前・ユーザーネーム・写真がまとまっている。情報を入れたら［完了］。
（別の入り方: 右上の［メニュー］→［アカウントセンター］→［プロフィール］→ 変えるプロフィールを選ぶ → 項目を編集 →［完了］。公式ヘルプには、こちらは今は一部の人だけが使える、とある）[^ig-edit]
（Android のアプリでも同じく［プロフィール］→［プロフィールを編集］→［完了］。）

1. **名前（表示名）**: 名前の欄を消して `AI Ground｜毎朝1分のAIニュース` を貼り、［完了］。
   - ⚠ 名前を変えられる回数の制限（「14日間に2回まで」とよく言われるもの）は、**公式ヘルプでは確かめられなかった**。制限にかかっても困らないよう、1 回で入れる。
2. **ユーザーネーム（@）**: ユーザーネームの欄に `ai_ground` を入れる。使えないと出たら `ai_ground_jp`、次に `ai_ground_daily` を試す。［完了］。
   - 空いているかどうかは、入れて保存できるかで分かる（ログインせずに外から見たときは、空きを確かめ切れなかった）。
   - 公式ヘルプでは、空いている名前を作る例として「ピリオド・数字・アンダーバーを足す」が挙がっている。[^ig-chars]
   - 多くの人に見られているアカウントは、ユーザーネームの変更に**審査が入ることがある**。また、フォロワーに変更が**通知されることがある**。[^ig-edit]
   - ⚠ 元のユーザーネームに戻せる条件（公式）: 「ほかの人がまだ取っていない」こと、「自分以外の使用中のアカウントから最近外されたものではない」こと。**「14日間は元に戻せる」という期間は、公式ヘルプには書かれていない**。手放した元の @ は、ほかの人が取れるようになると考えておく。[^ig-revert]
3. **プロフィール写真**: ［プロフィールを編集］の画面で［写真やアバターを編集］→ 写真の取り込み元（写真アプリ）を選び、入れておいた先輩のメイの画像を選ぶ（ここの「アバター」は Instagram にもともとある別の機能なので選ばない。**写真を選ぶ**）→ 丸い枠の中に顔とオレンジの耳飾りが入っていることを確かめる →［完了］。[^ig-photo]
4. **自己紹介（任意）**: 2026-09-23 に「プロフィール文は変えない」と決めているので、変えるならその例外としてオーナーが決める。変える場合の下書き（`／` は改行。特集の名前「Jev」は入れない = 特集ごとに書き換えないため）:
   - `話題のAIを、毎朝1分で。／案内役はメイ。何ができて、どう使えばいいかを短く紹介。／見返せるように保存しておいてください。`

[^ig-edit]: Instagram ヘルプセンター「Instagramのプロフィール情報を変更する方法」 https://www.facebook.com/help/instagram/583107688369069?locale=ja_JP&cms_platform=iphone-app （iPhone アプリの手順。Android は `cms_platform=android-app`。2026-09-30 確認。使える文字や名前の変更回数の制限は、このページには書かれていない）
[^ig-chars]: Instagram ヘルプセンター https://www.facebook.com/help/instagram/513717858639392?locale=ja_JP （ユーザーネームに「ピリオド、数字、アンダーバー」を足す例。文字数の上限は公式では確認できず。2026-09-30 確認）
[^ig-revert]: Instagram ヘルプセンター「Instagramのユーザーネームを以前使用していたものに戻すための条件」 https://www.facebook.com/help/instagram/876876079327341 （2026-09-30 確認）
[^ig-photo]: Instagram ヘルプセンター「Instagramの使用中のプロフィール写真を追加または変更する」 https://www.facebook.com/help/instagram/557544397610546?locale=ja_JP&cms_platform=iphone-app （iPhone アプリの手順。推奨サイズの記載は無し。2026-09-30 確認）

## 2. YouTube（スマホの YouTube アプリ）

**先に確かめること**: アプリのプロフィール写真をタップし、いま **「HAL- AI情報カフェ」（`@hal-ai-9000`）のチャンネル**になっていることを確かめる。別のチャンネルなら、アカウントの切り替えでこのチャンネルにしてから始める。

**変える場所**: プロフィール写真 →［チャンネルを表示］→ 編集（えんぴつ）のアイコン。[^yt-edit]

1. **チャンネル名**: 名前の横の編集アイコン → `AI Ground｜毎朝1分のAIニュース` を入れる →［保存］。
   - ⚠ チャンネル名は **14日間に2回まで**しか変えられない（小さな直しも 1 回に数えられると考え、1 回で入れる）。[^yt-edit]
   - ⚠ チャンネル名を変えると **認証バッジ（チェックマーク）が外れる**。ハンドルを変えても外れない。[^yt-badge] 認証の申し込みには登録者 10 万人が要る[^yt-badge]ので、登録者 203 人（2026-09-30）のこのチャンネルには今バッジは無く、名前を変えても失うものは無い。
   - 新しい名前が YouTube 全体に出そろうまで **数日かかる**ことがある。その間、古い名前「HAL- AI情報カフェ」が見える場所が残る。[^yt-edit]
   - 名前がまるごと変わるので、見ている人が「別のチャンネル？」と思いやすい。写真も同じ日に変える。
2. **ハンドル（@）**: **0 章の 3 で A（残す）を選んだら、ここはとばす。**
   B（変える）なら、ハンドルの横の編集アイコン → `ai_ground` を入れる（使えないと出たら `ai_ground_jp` → `ai_ground_daily`）→［保存］。
   - ハンドルは 3〜30 字。アンダーバー・ハイフン・ピリオドは使えるが、先頭と末尾には置けない。大文字と小文字は区別されない。[^yt-handle]
   - ⚠ ハンドルも **14日間に2回まで**。[^yt-edit]
   - 変えたあと **14日間は元の `@hal-ai-9000` が自分用に確保され、その間は元に戻せる**。この間は古い URL（`youtube.com/@hal-ai-9000`）も新しい URL も両方使える。**14日を過ぎると元のハンドルはほかの人が取れるようになる**。[^yt-handle-change]
3. **プロフィール写真**: 編集画面でプロフィール写真（丸）をタップ → 入れておいた先輩のメイの画像を選ぶ → 丸の中に顔が入っていることを確かめる →［保存］。
   - 使える形式は JPG・GIF・BMP・PNG（動く GIF は不可）、15MB 以下、98×98 ピクセルで表示できる画像。この画像は 1024×1024 の PNG で約 0.9MB なので条件を満たす。[^yt-photo]
4. **説明文**: 2026-09-23 の決定どおり**変えない**。例外として、説明文の中に旧名「HAL- AI情報カフェ」が書いてあれば、その名前だけを「AI Ground」に置き換えるかをオーナーが決める。

公式ヘルプで確かめられなかったこと: 名前やハンドルを変えるときの審査の有無、収益化しているチャンネルやブランドアカウント特有の注意。

[^yt-edit]: YouTube ヘルプ「YouTube チャンネルのプロフィールを管理する」 https://support.google.com/youtube/answer/2657964?hl=ja&co=GENIE.Platform%3DiOS （スマホでの手順、名前・ハンドルは 14 日間に 2 回まで、名前を変えると認証バッジが削除される、名前の反映に数日。2026-09-30 確認）
[^yt-badge]: YouTube ヘルプ https://support.google.com/youtube/answer/3046484?hl=ja （名前を変えるとバッジが外れて再申請が必要、ハンドルの変更では外れない、申し込みには登録者 10 万人が必要。2026-09-30 確認）
[^yt-handle]: YouTube ヘルプ「YouTube ハンドルについて」 https://support.google.com/youtube/answer/11585688?hl=ja （3〜30 字、使える記号と置けない位置、大文字小文字を区別しない。2026-09-30 確認）

## 3. 変えたあと、司令塔に伝えてほしいこと

次をそのまま書いて送ってもらえれば足りる。

```
名前を変えました（変えた日: 2026-__-__）
表示名: AI Ground｜毎朝1分のAIニュース（違う形にしたら: ________）
Instagram の @: ai_ground / ai_ground_jp / ai_ground_daily / 変えていない
YouTube の @: 残した（@hal-ai-9000） / ai_ground / ai_ground_jp / ai_ground_daily
写真: 先輩のメイの顔（IG ○/× ・ YouTube ○/×）　　IG の自己紹介: 変えた/変えていない
```

伝えてもらったら、オーナーの指示を受けて司令塔が次を直す（オーナーが自分で直してもよい）:

- 親 `sns-hub` の `CLAUDE.md` の収容プロジェクト表・6 アカウントの表にある IG / YouTube の名前（と、変えた場合は @）
- [account-identity.md](account-identity.md) の先頭に、実際の @・変えた日
- 親の戦略ファイル（`docs/strategy/genre-experiment.md` の台帳、`docs/strategy/figma-navi.md`）にある旧名。**戦略ファイルはオーナーの明示の指示でだけ書き換える決まり**なので、「名前を直して」と一言もらう
- YouTube の @ を変えた場合だけ: `@hal-ai-9000` のリンクを **変えてから 14 日以内に**直す（14 日を過ぎるとほかの人が取れるので、古いリンクがよその人のチャンネルを指さないように）
