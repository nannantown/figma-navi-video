# 名前・@・プロフィール写真を変える手順書（Instagram・YouTube／スマホで操作）

**決定: 名前 HAL AI（2026-09-30）／プロフィール写真 Codex 版の「Ai」**

## ⚠ 変える前に確認（2026-09-30 の確認で見つかったこと）

変える前に、次の 3 つをオーナーが読んで「それでも進める」かを決める。詳しい表・URL は [account-identity.md](account-identity.md) の「「HAL AI」の確認結果」。

1. **専門学校 HAL と紛らわしい**: 専門学校 HAL（HAL東京・大阪・名古屋）は「AI・プログラミングの専門学校」を名乗り、AI の学科を持つ。公式 IG は `@hal.ac.jp`、公式 YouTube は登録者 1.31 万人。**「HAL AI」だけだと、学校の AI の公式アカウントに見える**おそれがある。→ この手順書では、表示名にひとことを付ける形（`HAL AI｜毎朝1分のAIニュース`）をおすすめにした。
   - **オーナーが決めること**: 「専門学校HALとは関係ありません」という断り書きを、Instagram の自己紹介（1 章の 4）や YouTube の説明文（2 章の 4）に入れるか。学校の公式 YouTube は登録者が多いので、取り違えがいちばん起きやすいのは YouTube。ただし 2026-09-23 に「IG / YouTube のプロフィール文・説明文は変えない」と決めているので、入れるならその決定の例外になる。入れなければ、今の文のまま。
2. **素直な @ は取られている**: YouTube の `@hal_ai`（表示名がちょうど「HAL AI」・登録者 2 人）と `@halai`、Instagram の `hal_ai`・`halai`・`hal.ai` は既にある。YouTube には「HAL AI」という名前の小さなチャンネルもほかにある。→ YouTube は今の `@hal-ai-9000` をそのまま使い、Instagram は下の候補を上から試す。
3. **商標は公式で確かめられていない**: 特許庁 J-PlatPat は自動では開けず【未確認】。民間のサイト（非公式）で文字「ＨＡＬ」を調べると 26 件あり、見られた最初の 10 件の中に、**「ＨＡＬ」（登録 6557753・第 42 類 = ソフト・IT のサービス）**と、**第 41 類（教育・娯楽）を含む「ＨＡＬ ＳＰＯＲＴＳ」（登録 6237529）**があった。音が「ハル」の登録では、HAL研究所の「ＨＡＬＥＧＧ」（第 9・41・42 類）もあった。残りの 16 件は見られていない。ロボットスーツの CYBERDYNE も「HAL」を登録商標にしている（ここまでは公式サイトの表記。区分は非公式の情報で医療・機械などで、教育・配信・ソフトの区分は無い）。→ **変える前に、オーナーがパソコンで J-PlatPat を確かめる**（account-identity.md の「4. 商標」に 5 ステップの手順）。第 41 類・第 38 類（配信）・第 42 類に「存続」の登録があって紛らわしいかどうか迷ったら、弁理士に聞く。

この手順書は、オーナーが自分のスマホで Instagram と YouTube の名前・@・プロフィール写真を変えるためのもの。
作業した worker はどちらにもログインしておらず、設定は何も変えていない。

- 注意書きは **公式ヘルプで確かめたことだけ**を書いた（2026-09-30 に確認。出典は各節の終わり）。公式に書いていないことは「公式には書かれていない」と書いた

## 0. はじめに用意するもの

| 何 | 中身 |
|---|---|
| 表示名（IG と YouTube で同じ） | **① `HAL AI｜毎朝1分のAIニュース`（おすすめ）** ／ ② `HAL AI｜話題のAIを毎朝1分で` ／ ③ `HAL AI`（ひとことなし） |
| Instagram のユーザーネーム（上から順に試す） | ① `hal_ai_9000` ② `hal_ai_jp` ③ `halai_jp` |
| YouTube のハンドル | **① 変えない（今の `@hal-ai-9000` のまま。おすすめ）**。変えるなら上から: ② `@hal_ai_jp` ③ `@halai_jp` ④ `@hal-ai-jp` |
| プロフィール写真（決定） | このリポの `assets/brand/final/profile-icon.png`（1024×1024 の PNG） |

**表示名にひとことを付ける理由**: 「HAL AI」だけだと、専門学校 HAL の AI コースや、YouTube に既にある同名の小さなチャンネル（`@hal_ai` など）と見分けにくい。ひとことで「毎朝 1 分の AI 情報」だと分かれば、探している人にも伝わる。①は今の特集（毎朝のニュース）にも、特集が変わったあとの AI 全般の発信にも合う。②は「試す・使う」寄り。「学ぶ」「講座」など学校のような言葉は、専門学校と紛らわしくなるので入れていない。

**YouTube の @ を変えない理由**: 今の `@hal-ai-9000` には「hal-ai」が入っていて、新しい名前と合っている。変えなければ、これまでの動画説明・他のサイト・親のメモにある `youtube.com/@hal-ai-9000` のリンクも検索もそのまま使え、変えたあと 14 日で元の @ をほかの人に取られる心配（2 章の 2）もない。素直な `@hal_ai`・`@halai` はほかの人が使っているので、変えても「HAL AI」ぴったりの @ にはならない。

**Instagram の ① を `hal_ai_9000` にした理由**: YouTube の `@hal-ai-9000` とそろえるため（Instagram の例ではハイフンではなくアンダーバーを使った。公式ヘルプが挙げる足し方の例は「ピリオド・数字・アンダーバー」[^ig-chars]）。YouTube の @ を ②〜④ に変えた場合は、Instagram も**それと同じ文字列**を先に試す（両方の @ がそろう）。今の Instagram の @ は記録が無い（要オーナー確認）。今の @ が「figma」など昔の中身の言葉を含まず、HAL AI と合っているなら、変えずに残してもよい。（`hal.ai.jp` のようなピリオド区切りは、ウェブの住所に見えるので候補から外した。）

- 名前・@・写真は **同じ日にまとめて**変えるのがおすすめ（見た人が「別のアカウント？」と迷う期間を短くするため）。
- 空いているかどうかは、アプリで入力して保存できるかで分かる。2026-09-30 の時点では、YouTube の ②③④ に公開チャンネルは無かった（404）が、予約済みのものは外から見分けられない。Instagram の ①〜③ は、ログインせずには空きを確かめられなかった【確認できず】。

## 1. Instagram（スマホのアプリ）

**変える場所**（iPhone アプリの公式の手順）: 右下の［プロフィール］（または自分のプロフィール写真）→［プロフィールを編集］。ここに名前・ユーザーネーム・写真がまとまっている。情報を入れたら［完了］。
（別の入り方: 右上の［メニュー］→［アカウントセンター］→［プロフィール］→ 変えるプロフィールを選ぶ → 項目を編集 →［完了］。公式ヘルプには、こちらは今は一部の人だけが使える、とある）[^ig-edit]
（Android のアプリでも同じく［プロフィール］→［プロフィールを編集］→［完了］。）

1. **名前（表示名）**: 名前の欄を消して、0 章で選んだ表示名（おすすめ `HAL AI｜毎朝1分のAIニュース`）を貼り、［完了］。
   - ⚠ 名前を変えられる回数の制限（「14日間に2回まで」とよく言われるもの）は、**公式ヘルプでは確かめられなかった**。制限にかかっても困らないよう、決めた名前を 1 回で入れる。
2. **ユーザーネーム（@）**: ユーザーネームの欄に 0 章の ① `hal_ai_9000` を入れる。使えないと表示されたら ② `hal_ai_jp`、次に ③ `halai_jp` を試す。空いているものに決めて［完了］。
   - 公式ヘルプでは、空いている名前を作る例として「ピリオド・数字・アンダーバーを足す」が挙がっている（候補はどれもこの形）。[^ig-chars]
   - 多くの人に見られているアカウントは、ユーザーネームの変更に**審査が入ることがある**。また、フォロワーに変更が**通知されることがある**。[^ig-edit]
   - ⚠ 元のユーザーネームに戻せる条件（公式）: 「ほかの人がまだ取っていない」こと、「自分以外の使用中のアカウントから最近外されたものではない」こと。**「14日間は元に戻せる」という期間は、公式ヘルプには書かれていない**。手放した元の @ は、ほかの人が取れるようになると考えておく。[^ig-revert]
3. **プロフィール写真**: ［プロフィールを編集］の画面で［写真やアバターを編集］→ 写真の取り込み元（写真アプリなど）を選び、入れておいた `profile-icon.png` を選ぶ → 丸い枠の中に「Ai」全体が入っていることを確かめる →［完了］。[^ig-photo]
   - この画像は、丸く切っても字が欠けないように作ってある（字のいちばん外側でも、円の半径の 82% の位置までしかない）。拡大や位置の調整はしなくてよい。
4. **自己紹介（任意）**: 2026-09-23 に「プロフィール文は変えない」と決めているので、変えるならその例外としてオーナーが決める。変える場合は次の下書きを貼る（約 50 字。`／` は改行。特集の名前「Jev」は入れない = 特集ごとに書き換えないため）。
   - `話題のAIを、毎朝1分で。／何ができて、どう使えばいいかを短く紹介。／見返せるように保存しておいてください。`
   - 専門学校 HAL との取り違えが気になるときは、最後に `／※専門学校HALとは関係ありません` を足す。

[^ig-edit]: Instagram ヘルプセンター「Instagramのプロフィール情報を変更する方法」 https://www.facebook.com/help/instagram/583107688369069?locale=ja_JP&cms_platform=iphone-app （iPhone アプリの手順。Android は `cms_platform=android-app`。2026-09-30 確認。使える文字や名前の変更回数の制限は、このページには書かれていない）
[^ig-chars]: Instagram ヘルプセンター https://www.facebook.com/help/instagram/513717858639392?locale=ja_JP （ユーザーネームに「ピリオド、数字、アンダーバー」を足す例。文字数の上限は公式では確認できず。2026-09-30 確認）
[^ig-revert]: Instagram ヘルプセンター「Instagramのユーザーネームを以前使用していたものに戻すための条件」 https://www.facebook.com/help/instagram/876876079327341 （2026-09-30 確認）

## 2. YouTube（スマホの YouTube アプリ）

**先に確かめること**: アプリ右上（または下）のプロフィール写真をタップし、いま **「HAL- AI情報カフェ」（`@hal-ai-9000`）のチャンネル**になっていることを確かめる。別のチャンネルになっていたら、アカウントの切り替えで HAL のチャンネルにしてから始める。

**変える場所**: プロフィール写真 →［チャンネルを表示］→ 編集（えんぴつ）のアイコン。[^yt-edit]

1. **チャンネル名**: 名前の横の編集アイコン → 0 章で選んだ表示名（おすすめ `HAL AI｜毎朝1分のAIニュース`）を入れる →［保存］。
   - 「HAL- AI情報カフェ」から「HAL AI｜…」へは、頭の「HAL」が同じで**変わる部分は小さい**が、YouTube の扱いは普通の名前の変更と同じと考える。公式ヘルプには、変更の大きさで扱いが変わるという記載は無い。
   - ⚠ チャンネル名は **14日間に2回まで**しか変えられない（小さな直しも 1 回に数えられると考え、決めた名前を 1 回で入れる）。[^yt-edit]
   - ⚠ チャンネル名を変えると **認証バッジ（チェックマーク）が外れ**、付け直すにはもう一度申し込みが要る。ハンドルを変えてもバッジは外れない。[^yt-badge] 認証の申し込みには登録者 10 万人が要る[^yt-badge]ので、登録者 203 人（2026-09-30）のこのチャンネルには今バッジは無いはずで、バッジの点では、名前を変えても失うものは無い（2026-09-30 に公開ページを見たときも、バッジの印は見当たらなかった）。
   - 新しい名前が YouTube 全体に出そろうまで、**数日かかる**ことがある。その間、古い名前「HAL- AI情報カフェ」が見える場所が残る。[^yt-edit]
2. **ハンドル（@）**: **おすすめは変えない**（`@hal-ai-9000` のまま。この手順はとばしてよい）。変える場合だけ: ハンドルの横の編集アイコン → 0 章の ② `hal_ai_jp` を入れる。使えないと出たら ③ `halai_jp` → ④ `hal-ai-jp` の順に試す →［保存］。
   - ハンドルは 3〜30 字。アンダーバー・ハイフン・ピリオドは使えるが、先頭と末尾には置けない。大文字と小文字は区別されない。[^yt-handle]
   - ⚠ ハンドルも **14日間に2回まで**。[^yt-edit]
   - 変えたあと **14日間は元のハンドル `@hal-ai-9000` が自分用に確保され、その間は元に戻せる**。この間は古い URL（`youtube.com/@hal-ai-9000`）も新しい URL も両方使える。14日を過ぎると元のハンドルはほかの人が取れるようになる。[^yt-handle-change]
3. **プロフィール写真**: 編集画面でプロフィール写真（丸）をタップ → 送っておいた `profile-icon.png` を選ぶ →［保存］。
   - 使える形式は JPG・GIF・BMP・PNG（動く GIF は不可）、15MB 以下で、98×98 ピクセルで表示できる画像。`profile-icon.png` は 1024×1024 の PNG で約 26KB なので条件を満たしている。[^yt-photo]
4. **説明文**: 2026-09-23 の決定どおり**変えない**。例外として、(a) 説明文の中に旧名「HAL- AI情報カフェ」が書いてあればその名前だけを「HAL AI」に置き換える、(b) 冒頭の「⚠ 変える前に確認」の 1 で「断り書きを入れる」と決めた場合は `※専門学校HALとは関係ありません。` を 1 行足す。どちらもオーナーが決める（迷ったら司令塔に相談）。

公式ヘルプで確かめられなかったこと: 名前やハンドルを変えるときの審査の有無、収益化しているチャンネルやブランドアカウント特有の注意。

[^yt-edit]: YouTube ヘルプ「YouTube チャンネルのプロフィールを管理する」 https://support.google.com/youtube/answer/2657964?hl=ja&co=GENIE.Platform%3DiOS （スマホでの手順、名前・ハンドルは 14 日間に 2 回まで、名前を変えると認証バッジが削除される、名前の反映に数日。2026-09-30 確認）
[^yt-badge]: YouTube ヘルプ https://support.google.com/youtube/answer/3046484?hl=ja （名前を変えるとバッジが外れて再申請が必要、ハンドルの変更では外れない、申し込みには登録者 10 万人が必要。2026-09-30 確認）
[^yt-handle]: YouTube ヘルプ「YouTube ハンドルについて」 https://support.google.com/youtube/answer/11585688?hl=ja （3〜30 字、使える記号と置けない位置、大文字小文字を区別しない。2026-09-30 確認）

[^yt-photo]: YouTube ヘルプ「チャンネルのブランディングを管理する」 Android 版 https://support.google.com/youtube/answer/10456525?hl=ja&co=GENIE.Platform%3DAndroid ／ iPhone・iPad 版 https://support.google.com/youtube/answer/10456525?hl=ja&co=GENIE.Platform%3DiOS （どちらも手順と画像の条件は同じ。2026-09-30 確認）

## 3. 変えたあと、司令塔に伝えてほしいこと

次を、そのまま書いて送ってもらえれば足りる。

```
名前を変えました（変えた日: 2026-__-__）
表示名: ________（0 章の ①②③ のどれか）
Instagram の @: ________（0 章の ①〜③ のどれか / 変えていない）
YouTube の @: ________（変えていない = @hal-ai-9000 / ②〜④ のどれか）
写真: IG ○/× ・ YouTube ○/×　　IG の自己紹介: 変えた/変えていない
```

伝えてもらったら、オーナーの指示を受けて司令塔が次を直す（親の `CLAUDE.md` の注記どおり、オーナーが自分で直してもよい）:

- 親 `sns-hub` の `CLAUDE.md` の収容プロジェクト表・6 アカウントの表にある IG / YouTube の名前（と、変えた場合は @）
- [account-identity.md](account-identity.md) の先頭に、実際の @・変えた日
- 親の戦略ファイル（`docs/strategy/genre-experiment.md` の台帳、`docs/strategy/figma-navi.md`）にある旧名。**戦略ファイルはオーナーの明示の指示でだけ書き換える決まり**なので、「名前を直して」と一言もらう。YouTube の @ を変えた場合だけ、`@hal-ai-9000` のリンクも直す。元のハンドルは 14 日を過ぎるとほかの人が取れるので、古いリンクがほかの人のチャンネルを指さないよう、**変えてから 14 日以内に**直す
