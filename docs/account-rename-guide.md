**表示名にひとことを付ける理由**: 「May AI」だけだと、登録商標の「MayAI®」（AI の英語学習）や、YouTube に既にある同名のチャンネル、英語の「5月の AI」と見分けにくい。ひとことで「毎朝 1 分の AI 情報」だと分かれば、探している人にも伝わる。①は今の特集（毎朝のニュース）にも、特集が変わったあとの AI 全般の発信にも合う。②は「試す・使う」寄り。「学ぶ」「講座」など教室のような言葉は、英語学習の「MayAI®」と見分けにくくなるので入れていない（これも見分けやすさのためで、商標の対策ではない）。読み方を聞かれたら「メイ エーアイ」。

**YouTube の @ を変えるかどうか（オーナーが決める・冒頭の囲みの ④）**:

| | 変える（`@may_ai_jp` など） | 変えない（`@hal-ai-9000` のまま） |
|---|---|---|
| 良いところ | 名前「May AI」と @ がそろい、Instagram とも同じ @ になる | これまでの動画の説明・ほかのサイト・親のメモにあるリンク（`youtube.com/@hal-ai-9000`）がずっと使える |
| 気になるところ | 元の `@hal-ai-9000` は 14 日を過ぎるとほかの人が取れるようになる（2 章の 2）。それまでに親のメモなどのリンクを直す必要がある（3 章） | 名前は May AI なのに @ に旧名の「hal」が残る |

HAL AI のときは @ に「hal-ai」が入っていたので「変えない」をおすすめにしたが、May AI では名前と合わなくなるので、どちらをおすすめにするかは決めていない。

**`may_ai_jp` を ① にした理由**: `may_ai`（YouTube・Instagram とも使用中）に日本の `jp` を足した形で、名前と一目で結びつく。YouTube では 404（公開チャンネルなし）だった。②③は名前に言葉を足した形（`daily` = 毎日、`ask` = 聞く）。Instagram の ①〜③ はログインせずには空きを確かめられなかった【確認できず】。YouTube の ①〜③ は 404 だったが、予約済みのものは外から見分けられない。（候補から外したもの: `may.ai.jp` はピリオド区切りでウェブの住所に見えるため。`mayai_jp` は Instagram で使用中のため。`may-ai` は YouTube で 404 だったが、使用中の `@may_ai` と記号 1 つしか違わないため。）

- 名前・@・写真は **同じ日にまとめて**変えるのがおすすめ（見た人が「別のアカウント？」と迷う期間を短くするため）。
- 空いているかどうかは、アプリで入力して保存できるかで分かる。

## 1. Instagram（スマホのアプリ）

**変える場所**（iPhone アプリの公式の手順）: 右下の［プロフィール］（または自分のプロフィール写真）→［プロフィールを編集］。ここに名前・ユーザーネーム・写真がまとまっている。情報を入れたら［完了］。
（別の入り方: 右上の［メニュー］→［アカウントセンター］→［プロフィール］→ 変えるプロフィールを選ぶ → 項目を編集 →［完了］。公式ヘルプには、こちらは今は一部の人だけが使える、とある）[^ig-edit]
（Android のアプリでも同じく［プロフィール］→［プロフィールを編集］→［完了］。）

1. **名前（表示名）**: 名前の欄を消して、0 章で選んだ表示名（おすすめ `May AI｜毎朝1分のAIニュース`）を貼り、［完了］。
   - ⚠ 名前を変えられる回数の制限（「14日間に2回まで」とよく言われるもの）は、**公式ヘルプでは確かめられなかった**。制限にかかっても困らないよう、決めた名前を 1 回で入れる。
2. **ユーザーネーム（@）**: ユーザーネームの欄に 0 章の ① `may_ai_jp` を入れる。使えないと表示されたら ② `mayai_daily`、次に ③ `askmayai` を試す。空いているものに決めて［完了］。
   - 公式ヘルプでは、空いている名前を作る例として「ピリオド・数字・アンダーバーを足す」が挙がっている（① はこの形。②③ は言葉を足した形）。[^ig-chars]
   - 多くの人に見られているアカウントは、ユーザーネームの変更に**審査が入ることがある**。また、フォロワーに変更が**通知されることがある**。[^ig-edit]
   - ⚠ 元のユーザーネームに戻せる条件（公式）: 「ほかの人がまだ取っていない」こと、「自分以外の使用中のアカウントから最近外されたものではない」こと。**「14日間は元に戻せる」という期間は、公式ヘルプには書かれていない**。手放した元の @ は、ほかの人が取れるようになると考えておく。[^ig-revert]
3. **プロフィール写真（アバターの顔にすると決めた場合だけ。今の Ai のままならとばす）**: ［プロフィールを編集］の画面で［写真やアバターを編集］→ 写真の取り込み元（写真アプリなど）を選び（ここの「アバター」は Instagram にもともとある別の機能なので選ばない。**写真を選ぶ**）、入れておいた `profile-icon.png` を選ぶ → 丸い枠の中に顔と目印（A は耳飾り、B は頭の上の丸、C はサイドポニー）が入っていることを確かめる →［完了］。[^ig-photo]
   - 丸く切ったときの見え方は `assets/brand/may-2026-09-30/<案>/preview.png` で確かめてある（下書き。選んだ案で最終版にするときに、欠ける所が無いかをもう一度書く）。
4. **自己紹介（任意）**: 2026-09-23 に「プロフィール文は変えない」と決めているので、変えるならその例外としてオーナーが決める。変える場合は次の下書きを貼る（約 50 字。`／` は改行。特集の名前「Jev」は入れない = 特集ごとに書き換えないため）。
   - `話題のAIを、毎朝1分で。／何ができて、どう使えばいいかを短く紹介。／見返せるように保存しておいてください。`
   - 案内役のキャラクターを出すと決めたら、`案内役はメイ。` のような 1 行を足すかどうかもオーナーが決める（下書きには入れていない）。

## 2. YouTube（スマホの YouTube アプリ）

**先に確かめること**: アプリ右上（または下）のプロフィール写真をタップし、いま **「HAL- AI情報カフェ」（`@hal-ai-9000`）のチャンネル**になっていることを確かめる。別のチャンネルになっていたら、アカウントの切り替えでこのチャンネルにしてから始める。

**変える場所**: プロフィール写真 →［チャンネルを表示］→ 編集（えんぴつ）のアイコン。[^yt-edit]

1. **チャンネル名**: 名前の横の編集アイコン → 0 章で選んだ表示名（おすすめ `May AI｜毎朝1分のAIニュース`）を入れる →［保存］。
   - 「HAL- AI情報カフェ」から「May AI｜…」へは名前がまるごと変わるので、見ている人が「別のチャンネル？」と思いやすい。写真と @ も同じ日に変え、変えた日の動画で名前が変わったことを伝えるかはオーナーが決める（動画の中身を変えるのは別のカード）。
   - ⚠ チャンネル名は **14日間に2回まで**しか変えられない（小さな直しも 1 回に数えられると考え、決めた名前を 1 回で入れる）。[^yt-edit]
   - ⚠ チャンネル名を変えると **認証バッジ（チェックマーク）が外れ**、付け直すにはもう一度申し込みが要る。ハンドルを変えてもバッジは外れない。[^yt-badge] 認証の申し込みには登録者 10 万人が要る[^yt-badge]ので、登録者 203 人（2026-09-30）のこのチャンネルには今バッジは無いはずで、バッジの点では、名前を変えても失うものは無い（2026-09-30 に公開ページを見たときも、バッジの印は見当たらなかった）。
   - 新しい名前が YouTube 全体に出そろうまで、**数日かかる**ことがある。その間、古い名前「HAL- AI情報カフェ」が見える場所が残る。[^yt-edit]
2. **ハンドル（@）**: ハンドルの横の編集アイコン → Instagram で取れたものと同じ文字列を入れる（Instagram が ① `may_ai_jp` なら `may_ai_jp`）。使えないと出たら 0 章の ① `may_ai_jp` → ② `mayai_daily` → ③ `askmayai` の順に試す →［保存］。**リンク切れを避けたいなら変えずに `@hal-ai-9000` のままでもよい**（0 章の「YouTube の @ を変えるかどうか」）。
   - ハンドルは 3〜30 字。アンダーバー・ハイフン・ピリオドは使えるが、先頭と末尾には置けない。大文字と小文字は区別されない。[^yt-handle]
   - ⚠ ハンドルも **14日間に2回まで**。[^yt-edit]
   - 変えたあと **14日間は元のハンドル `@hal-ai-9000` が自分用に確保され、その間は元に戻せる**。この間は古い URL（`youtube.com/@hal-ai-9000`）も新しい URL も両方使える。14日を過ぎると元のハンドルはほかの人が取れるようになる。[^yt-handle-change]
3. **プロフィール写真（アバターの顔にすると決めた場合だけ）**: 編集画面でプロフィール写真（丸）をタップ → 送っておいた `profile-icon.png` を選ぶ →［保存］。
   - 使える形式は JPG・GIF・BMP・PNG（動く GIF は不可）、15MB 以下で、98×98 ピクセルで表示できる画像。アバターの `profile-icon.png` は 1024×1024 の PNG で約 0.7〜1MB なので条件を満たしている。[^yt-photo]
4. **説明文**: 2026-09-23 の決定どおり**変えない**。例外として、説明文の中に旧名「HAL- AI情報カフェ」が書いてあればその名前だけを「May AI」に置き換えるかを、オーナーが決める（迷ったら司令塔に相談）。

公式ヘルプで確かめられなかったこと: 名前やハンドルを変えるときの審査の有無、収益化しているチャンネルやブランドアカウント特有の注意。
