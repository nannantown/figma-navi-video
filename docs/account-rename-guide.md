# 「AIの手習い」に変える手順書（Instagram・YouTube／スマホで操作）

2026-09-30 にオーナーが **B「AIの手習い」**（アイコンは Codex 版の「Ai」）に決めた。この手順書は、オーナーが自分のスマホで Instagram と YouTube の名前・@・プロフィール写真を変えるためのもの。
作業した worker はどちらにもログインしておらず、設定は何も変えていない。

- 決めたことの記録・アイコンの作り方・商標の確認: [account-identity.md](account-identity.md) の先頭
- 注意書きは **公式ヘルプで確かめたことだけ**を書いた（2026-09-30 に確認。出典は各節の終わり）。公式に書いていないことは「公式には書かれていない」と書いた

## 0. はじめに用意するもの

| 何 | 中身 |
|---|---|
| 表示名（IG と YouTube で同じ） | `AIの手習い｜毎朝1分、触って覚える` |
| Instagram のユーザーネーム（上から順に試す） | ① `ai_tenarai` ② `aitenarai` ③ `ai.tenarai` |
| YouTube のハンドル（上から順に試す） | ① `@AIの手習い` ② `@ai_tenarai` ③ `@aitenarai` ④ `@ai.tenarai` |
| プロフィール写真 | このリポの `assets/brand/final/profile-icon.png`（1024×1024 の PNG） |

- 名前・@・写真は **同じ日にまとめて**変えるのがおすすめ（見た人が「別のアカウント？」と迷う期間を短くするため）。
- 空いているかどうかは、アプリの入力欄に打つとその場で分かる。2026-09-30 の時点では YouTube の上の @ に公開チャンネルは無かったが、予約済みのものは外から見分けられない。Instagram はログインしないと確かめられなかった。

### 画像をスマホに送る方法（一例: Mac から iPhone へ AirDrop）

1. Mac の Finder で `~/projects/sns-hub/figma-navi-video/assets/brand/final/` を開く（司令塔がこの作業を main に入れたあと。入る前なら司令塔に「profile-icon.png をちょうだい」と伝える）。
2. `profile-icon.png` を右クリック →「共有」→「AirDrop」→ 自分の iPhone を選ぶ。
3. iPhone で受け取ると「写真」アプリに入る。あとはアプリの写真選びでこの画像を選ぶ。

（AirDrop が使えないときは、自分あてのメールやメモに画像を貼って、スマホ側で「画像を保存」でもよい。）

## 1. Instagram（スマホのアプリ）

**変える場所**: 自分のプロフィール画面 →［プロフィールを編集］。ここに名前・ユーザーネーム・写真がまとまっている。変えたら［完了］。
（別の入り方: ［メニュー］→［アカウントセンター］→［プロフィール］→ 変える項目 →［完了］）[^ig-edit]

1. **名前（表示名）**: 名前の欄を消して `AIの手習い｜毎朝1分、触って覚える` を貼り、［完了］。
   - ⚠ 名前を変えられる回数の制限（「14日間に2回まで」とよく言われるもの）は、**公式ヘルプでは確かめられなかった**。制限にかかっても困らないよう、決めた名前を 1 回で入れる。
2. **ユーザーネーム（@）**: ユーザーネームの欄に ① `ai_tenarai` を入れる。「使用できません」と出たら ② `aitenarai`、次に ③ `ai.tenarai` を試す。空いているものに決めて［完了］。
   - 公式ヘルプでは、空いている名前を作る例として「ピリオド・数字・アンダーバーを足す」が挙がっている（候補の ② ③ もこの形）。[^ig-chars]
   - 多くの人に見られているアカウントは、ユーザーネームの変更に**審査が入ることがある**。また、フォロワーに変更が**通知されることがある**。[^ig-edit]
   - ⚠ 元のユーザーネームに戻せる条件（公式）: 「ほかの人がまだ取っていない」こと、「自分以外の使用中のアカウントから最近外されたものではない」こと。**「14日間は元に戻せる」という期間は、公式ヘルプには書かれていない**。手放した元の @ は、ほかの人が取れるようになると考えておく。[^ig-revert]
3. **プロフィール写真**: ［写真を変更］→［写真をアップロード］→ 送っておいた `profile-icon.png` を選ぶ →（丸い枠の中に「Ai」全体が入っていることを確かめて）→［完了］。[^ig-photo]
   - この画像は、丸く切っても字が欠けないように作ってある（字のいちばん外側でも、円の半径の 82% の位置までしかない）。拡大や位置の調整はしなくてよい。
4. **自己紹介（任意）**: 変える場合は [account-identity.md](account-identity.md) の「プロフィール文の下書き」の **B AIの手習い** を貼る。

[^ig-edit]: Instagram ヘルプセンター「Instagramのプロフィール情報を変更する方法」 https://www.facebook.com/help/instagram/583107688369069?locale=ja_JP （2026-09-30 確認）
[^ig-chars]: Instagram ヘルプセンター https://www.facebook.com/help/instagram/513717858639392?locale=ja_JP （ユーザーネームに「ピリオド、数字、アンダーバー」を足す例。文字数の上限は公式では確認できず。2026-09-30 確認）
[^ig-revert]: Instagram ヘルプセンター「Instagramのユーザーネームを以前使用していたものに戻すための条件」 https://www.facebook.com/help/instagram/876876079327341 （2026-09-30 確認）
[^ig-photo]: Instagram ヘルプセンター「Instagramの使用中のプロフィール写真を追加または変更する」 https://www.facebook.com/help/instagram/557544397610546?locale=ja_JP （推奨サイズの記載は無し。2026-09-30 確認）

## 2. YouTube（スマホの YouTube アプリ）

**先に確かめること**: アプリ右上（または下）のプロフィール写真をタップし、いま **「HAL- AI情報カフェ」（`@hal-ai-9000`）のチャンネル**になっていることを確かめる。別のチャンネルになっていたら、アカウントの切り替えで HAL のチャンネルにしてから始める。

**変える場所**: プロフィール写真 →［チャンネルを表示］→ 編集（えんぴつ）のアイコン。[^yt-edit]

1. **チャンネル名**: 名前の横の編集アイコン → `AIの手習い｜毎朝1分、触って覚える` を入れる →［保存］。
   - ⚠ チャンネル名は **14日間に2回まで**しか変えられない。[^yt-edit]
   - ⚠ チャンネル名を変えると **認証バッジ（チェックマーク）が外れ**、付け直すにはもう一度申し込みが要る（このチャンネルに今バッジが付いていなければ関係ない）。ハンドルを変えてもバッジは外れない。[^yt-badge]
   - 新しい名前が YouTube 全体に出そろうまで、**数日かかる**ことがある。[^yt-edit]
2. **ハンドル（@）**: ハンドルの横の編集アイコン → ① `AIの手習い` を入れる。使えないと出たら ② `ai_tenarai` → ③ `aitenarai` → ④ `ai.tenarai` の順に試す →［保存］。
   - ハンドルは基本 3〜30 字。日本語も使え、漢字は 1〜10 字などの決まりがある。[^yt-handle]
   - ⚠ ハンドルも **14日間に2回まで**。[^yt-edit]
   - 変えたあと **14日間は元のハンドル `@hal-ai-9000` が自分用に確保され、その間は元に戻せる**。この間は古い URL（`youtube.com/@hal-ai-9000`）も新しい URL も両方使える。14日を過ぎると元のハンドルはほかの人が取れるようになる。[^yt-handle-change]
3. **プロフィール写真**: 編集画面でプロフィール写真（丸）をタップ → 送っておいた `profile-icon.png` を選ぶ →［保存］。
   - 使える形式は JPG・GIF・BMP・PNG（動く GIF は不可）、15MB 以下で、98×98 ピクセルで表示できる画像。`profile-icon.png` は 1024×1024 の PNG で約 26KB なので条件を満たしている。[^yt-photo]
4. **説明文**: 2026-09-23 の決定どおり**変えない**（説明文の中に旧名「HAL- AI情報カフェ」が書いてあって気になるときは、司令塔に相談）。

公式ヘルプで確かめられなかったこと: 名前やハンドルを変えるときの審査の有無、収益化しているチャンネルやブランドアカウント特有の注意。

[^yt-edit]: YouTube ヘルプ「YouTube チャンネルのプロフィールを管理する」 https://support.google.com/youtube/answer/2657964?hl=ja&co=GENIE.Platform%3DiOS （スマホでの手順、名前・ハンドルは 14 日間に 2 回まで、名前の反映に数日。2026-09-30 確認）
[^yt-badge]: YouTube ヘルプ https://support.google.com/youtube/answer/3046484?hl=ja （名前を変えるとバッジが外れて再申請が必要、ハンドルの変更では外れない。2026-09-30 確認）
[^yt-handle]: YouTube ヘルプ「YouTube ハンドルについて」 https://support.google.com/youtube/answer/11585688?hl=ja （2026-09-30 確認）
[^yt-handle-change]: YouTube ヘルプ「ハンドルを変更、確認、非表示にする」 https://support.google.com/youtube/answer/15920820?hl=ja&co=GENIE.Platform%3DAndroid （旧ハンドルは 14 日間保持、その間は元に戻せ、新旧どちらの URL も使える。2026-09-30 確認）
[^yt-photo]: YouTube ヘルプ「チャンネルのブランディングを管理する」 https://support.google.com/youtube/answer/10456525?hl=ja&co=GENIE.Platform%3DAndroid （2026-09-30 確認）

## 3. 変えたあと、司令塔に伝えてほしいこと

次の 4 つを、そのまま書いて送ってもらえれば足りる。

```
AIの手習いに変えました（変えた日: 2026-__-__）
Instagram の @: ________（① ai_tenarai ② aitenarai ③ ai.tenarai のどれになったか）
YouTube の @: ________（① AIの手習い ② ai_tenarai ③ aitenarai ④ ai.tenarai のどれになったか）
写真: IG ○/× ・ YouTube ○/×　　IG の自己紹介: 変えた/変えていない
```

伝えてもらったら、司令塔が次を直す（オーナーの指示を受けてから）:

- 親 `sns-hub` の `CLAUDE.md` の収容プロジェクト表・6 アカウントの表にある IG / YouTube の名前と @
- [account-identity.md](account-identity.md) の先頭の「採用」に、実際の @ と変えた日
- 親の戦略ファイル（`docs/strategy/genre-experiment.md` の台帳、`docs/strategy/figma-navi.md`）にある旧名・`@hal-ai-9000` のリンク。**戦略ファイルはオーナーの明示の指示でだけ書き換える決まり**なので、「名前を直して」と一言もらう。YouTube の元のハンドルは 14 日を過ぎるとほかの人が取れるので、古いリンクがほかの人のチャンネルを指さないよう、**変えてから 14 日以内に**直すのがよい
